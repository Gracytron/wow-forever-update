WoW Forever parody site — publish on GitHub Pages

1. Create a PUBLIC GitHub repository named wow-forever-update.
2. Upload index.html, preview.jpg, banner.jpg, and .nojekyll into its root.
3. IMPORTANT: Edit index.html and replace YOUR_USERNAME with your actual GitHub username in og:image URL.
4. Go to Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Your URL will be https://YOUR_USERNAME.github.io/wow-forever-update/ (replace YOUR_USERNAME).
6. Post the URL by itself in Discord so Discord generates a preview.

The webpage automatically reveals the Rickroll after ~4 seconds and opens YouTube.
The preview image and webpage contain the fandom branding for a joke, with parody disclosure.
